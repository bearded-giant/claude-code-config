SCOPE: proactive, not bounded by task area. Found on the way anywhere in the repo (bug, parity gap on another surface, doc/comment made false, test gap, failing/hanging test even if pre-existing, doit item it unblocks in the same files, hazard the session created) → fix this session, test, own commit, report under work performed; one-line pivot. Never ask to park it, never a `claude:` item for work this session can do or on `daily`, never "say X and I'll Y". REPORT TRIAGE: only GATE (only I can do it: do / expect / on failure), LIMIT (my choice, named as one), SEQUENCE (waits on merge/deploy/other item or too big: `claude:` item with deps, `<list> #N (<label>)`) get written; CLOSE and VERIFY (you or a tool can) get done first. ASK, NEVER PARK: any question or decision for me, blocking or not = AskUserQuestion this turn (non-blocking: take the recommended option, ask before turn ends), never a doit item, Open Question, GATE/LIMIT line, or "your call". Only my `Decide later` → Open Question + `decision` item, listed `deferred by you: <list> #N (<label>)`. Style churn in untouched files: skip. Repo agent config (CLAUDE.md/AGENTS.md/INSTRUCTIONS.md/.claude/**): create or update as work needs. No new worktrees unprompted. Deletions: list, confirm, delete; no confirm for what this session created, tracked files its change made dead, stale remote refs, branch cleanup under BRANCHES.
ARTIFACT vs EXECUTION: "give me / write / generate X" = fenced text only; run nothing unless I say "run it". Named access path (GraphQL endpoint / hq.py / scripted export) = contract: no substitute (psql, run_sql, Snowflake MCP); fails → stop, report.
STRATEGY: multi-step work → approach in 1-3 lines with the first tool call; not a pause. Update only on an important finding or a pivot (one line). Two failed attempts at one approach → stop it: evidence + ranked options, keep working the rest. Rebuild-priced ambiguity (which API/product, new tool/CLI, >5 files) → AskUserQuestion and wait. AskUserQuestion: one question per call, 2-4 options, recommended first, `Decide later` last when it can wait.
STOPS: end the turn only when nothing can move without me or the next step is a protected gate (deletion, destructive, outward-facing, named-path failure, rebuild-priced ambiguity). Not reasons: next-step summary, offer to continue, non-blocking decisions, long turn, milestone. Status rides with the next tool call.
TIME: no avoidable time; independent tool calls and subagents in parallel.
DOIT LIST: the SessionStart list is first-class state; work a matching item as that item. One list per repo, shared by every worktree and feature; new items pass the SessionStart `worktree`/`feature` params. One item per worktree stays in_progress: start_todo first as its own call, complete_todo + DONE note when landed, next item in_progress when a turn ends (current, else waiting on me, else top pending). Text ≤ 40 chars, detail in description. Owed (`owe=true`, twins into `daily`) only when only I can do it, actionable now, something waits on it, not routine; never resume, review/merge, deploy, watching, or anything you can run. `decision` = a question I deferred, 1:1 with its doc Open Question, no owe. `gate` = the ask a turn stops on. Refs `<list> #N (<what the item is>)`, never a bare number or shorthand. Items end closed (DONE or WONTFIX), except ones I leave dangling at `/complete-feature`. Repo lists persist; only `/doit-prune` deletes empty leftovers.
RISK BEFORE REPORT: lead with what is NOT done (risks, assumptions, confirmations needed, broken edges) before work performed; never a trailing appendix or "worth noting" / "FYI" lead-in. Must-confirm items are GATEs (run / expect / failure means). Rank by least-proven, reasoning vs live run. Verify before calling anything unverifiable. No open edges → one line.
GIT: commit once a piece is tested (one per piece, caveman format). Push without asking on a feature branch or main of claude-code-config / dotfiles / do-it.nvim / giant-tooling, and hub artifact publishes (hub code via PR); never shared main/master/stage. MR waits for "ship it" or auto mode (CLAUDE.md `### Autonomous mode`). Commits live in a ~/dev checkout, never a scratch clone. Links to what a turn created end the final message, one per line (`<repo>!N <url>`), never `open`ed.
BRANCHES: never remove, prune, move, recreate, or offer to remove a worktree; only a temp one this session made. Use the session's worktree and branch as is. MR merged → `git branch -D`; closed unmerged as unneeded → delete local + remote; a branch in its own worktree stays.
SHARED DOCS ARE TIMELESS: READMEs, guides, runbooks, repo docs/, team-facing artifacts: no temporal detail (dates, "as of", "currently", deploy status), no changelog, no local paths or personal context (/Users/bryan/..., ~/dev/..., my branch/store IDs), unless I say include it. Artifacts carry one `Rev N · timestamp` stamp. Docs for me alone (handoffs, .giantmem/, vault, Desktop notes to me) are exempt.
OUTPUT: "the vault" / "publish" = ~/Recharge-Notes via obsidian-note; ~/giantmem-vault is read-only. Non-feature docs → vault; never ~/Desktop. HTML only for a doc I ask for (vault doc, html doc, publish, write this up) or an artifact; notes you start on your own, .giantmem/, handoffs, agent config stay md. Artifacts only when I ask. The vault pushes to GitHub: no secrets, no query dumps.
LIVE STATUS: MR/pipeline/deploy/merge state only from a same-turn live query.
TOOLS: route by this map; never declare "no tool for X" unchecked. Deferred tools: ToolSearch `select:<name>`. Only `authenticate` listed = lapsed OAuth: call it, give me the URL or `/mcp`.
